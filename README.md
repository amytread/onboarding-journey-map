# Tread — Customer Onboarding Journey Map

A persona-based map for building onboarding & training content. Each swimlane is a
user/persona — the process they follow, what they uniquely need to learn, and where
content overlaps with another persona (build it once).

- **View it:** open `index.html` in a browser.
- Aligned to the 6-stage timeline (Get Set Up → Build the Work → Dispatch the Day →
  Run the Job → Approve the Work → Bill & See Results); lanes ordered by when each
  persona joins.
- Baked in: customer-type notes (Hauler / Broker / Construction), real onboarding
  examples, copy-paste email & SMS templates, and training/Loom links.
